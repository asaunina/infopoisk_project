# infopoisk_project

## Описание проекта

Команда проекта: Мария Обридко, Анастасия Саунина.

Здесь хранятся наши данные и код для проекта по инфопоиску. 

Корпус текстов, на котором мы реализуем поиск, получается с сайта с текстами Льва Толстого. В целях экономии ресурсов мы взяли лишь одно произведение -- "Анну Каренина", однако представленный код даёт возможность скачать большее количество произведений (количество скачиваемых с сайта произведений -- параметр, задаваемый пользователем). Текст мы делим на предложения. Таким образом, один документ -- одно предложение.

Мы реализуем три варианта индексирования:

1) BM-25;
2) обученная на корпусе модель Word2Vec;
3) статическая модель FastText.

Есть возможность запустить код через cli. Также реализован веб-интерфейс, поддерживающий поиск.

## Структура репозитория

- В папке ```data``` -- итоговый корпус и код для его получения и предобработки.
- В папке ```search``` -- файлы с методами индексации и поиска, реализация cli.
- В папке ```infosearch_project``` -- файлы для запуска поиска на сайте.

Подробное описание содержимого каждой папки находится в ридми этой папки.

## Как использовать

Мы уже реализовали сбор данных для корпуса, итоговый файл с текстами ```corpus.json``` находится в папке ```data```. Однако у пользователя есть возможность скачать большее или меньшее количество текстов с сайта и предобработать их, используя функции в файлах ```tolstoy_crawler.ipynb``` и ```preprocessing.ipynb``` той же папки ```data```.

В папке ```search``` представлены основные .py файлы с реализацией трёх методов поиска:

- ```bm25.py``` -- в качестве скоров базовые bm-25-скоры;
- ```word2vec.py``` -- в качестве скоров косинусная близость векторов запроса и предложения;
- ```fasttext.py``` -- в качестве скоров косинусная близость векторов запроса и предложения.

В каждом файле находится класс -- соответствующий метод. Реализованы основные методы ```.fit()```, который строит индекс, и ```.search()```, принимающий на вход запрос пользователя и количество документов в выдаче. Также в зависимости от реализации могут быть другие методы класса.

Основной файл ```search.py``` содержит класс, который, в зависимости от указанного пользователем при инициализации метода, обращается к нужному файлу и достаёт оттуда класс с методом поиска.

В файле ```cli.py``` представлена реализация Command Line Interface. Собственно это один из методов использования нашего корпуса: через командную строку. Пользователю необходимо указать:

1) текст запроса (```query```);
2) метод индексирования (```method```): поддерживается три метода -- bm25, word2vec, fasttext;
3) количество документов в выдаче (```top_n```);
4) путь к файлу с корпусом (```corpus```): предполагается, что корпус в формате, который мы задаём при препроцессинге.

Пример работы через командную строку: ```python cli_search.py --query "Всё смешалось в доме Облонских!" --method fasttext --top-n 20 --corpus data/corpus.json```.

Кроме CLI, запустить поиск можно через сайт. Код для реализации веб-интерфейса представлен в папке ```infosearch_project```. Веб-интерфейс имеет три страницы:

1) главная страница;
2) страница поиска с выбором параметров;
3) страница с результатами поиска, где также выводится время поиска.

Также в репозитории представлен файл ```plan.docx```, в котором описан подробный план, показывающий соответствие проекту всем требуемым пунктам.
