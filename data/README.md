# Описание корпуса и структура папки

В настоящей папке представлен код для сборки корпуса, по которому производится поиск.

## Получение данных 

В качестве корпуса мы выбрали полный текст произведения "Анна Каренина" Льва Толстого. Текст мы получаем с сайта http://tolstoy-lit.ru/tolstoy/proza/index.htm.

В файле ```tolstoy_preprocessing.ipynb``` представлен код для скачивания текстов с указанного сайта. Там можно настроить параметр: количество скачиваемых текстов. Но в рамках проекта мы решили ограничиться скачиванием только одного текста, но объём произведения достаточно большой, и в итоге в корпусе получается достаточно много предложений.

Информация из корпуса скачивается в файл ```books_data.json``` в следующем виде. Для каждой главы книги сохраняется метаинформация:

- ```'book_url'``` -- ссылка на текст книги;

- ```'book_title'``` -- название книги;

- ```'chapter_name'``` -- название (номер) главы;

- ```'chapter_text'``` -- полный текст главы.

Так как мы рассматриваем только один текст, первые два поля для всех записей в корпусе будут одинаковыми.

## Предобработка данных

Полученные данные предобрабатываются. Код представлен в файле ```preprocessing.ipynb```.

Тексты глав делятся на предложения, затем происходит следующая предобработка:

- токенизация с помощью word_tokenize из nltk;

- лемматизация;

- чистка от пунктуации;

- чистка от стоп-слов;

- приведение к нижнему регистру;

- удаление прочих спец. символов (например, английских / французских слов).

После предобработки информация о текстах глав сохраняется в файл ```corpus.json```, откуда впоследствии мы будем извлекать информацию.

Для каждой главы сохраняется следующая информация:

- ```'book_url'``` -- ссылка на текст книги;

- ```'book_title'``` -- название книги;

- ```'chapter_name'``` -- название (номер) главы;

- ```'chapter_text'``` -- полный текст главы;

- ```'chapter_text_sent_lemmas'``` -- список списков лемм по предложениям (т.е. предобработанные предложения);

- ```'chapter_sentences'``` -- список предложений для главы.
