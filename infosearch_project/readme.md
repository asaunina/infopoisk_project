В данной папке находятся файлы для использования нашего поиска на сайте.

- Папка **templates** -- html-файлы для каждой страницы
- Папка **static** -- style.css для оформления
- **214.zip** -- модель ```geowac_tokens_none_fasttextskipgram_300_5_2020``` с сайта https://rusvectores.org/en/models/.
- **corpus.json** -- корпус текстов Л.Н.Толстого, собранный в папке data
- **app.py** -- flask-код для запуска страниц
- .py файлы из папки **search**
