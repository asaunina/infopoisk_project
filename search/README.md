# Поиск

В настоящей папке репозитория представлен код для реализации поиска с помощью трёх методов: bm25, word2vec, fasttext.

## BM25

Код с реализацией этого метода находится в файле ```bm25.py```. Используется построение обратного индекса с помощью библиотеки ```rank_bm25``` (класс ```BM25Okapi```).

## Word2Vwc

Код с реализацией этого метода находится в файле ```word2vec.py```. Для обучения word2vec модели используется библиотека ```gensim```. Все параметры для обучения дефолтные. При построении эмбеддингов документов мы получаем усреднённый эмбеддинг слов, входящих в него. То же самое при обработке запроса: усреднённый эмбеддинг термов из запроса. Для оценки используется косинусная близость.

## FastText

Используем модель ```geowac_tokens_none_fasttextskipgram_300_5_2020``` с сайта https://rusvectores.org/en/models/. 

К сожалению, из-за слишком большого размера модели, загрузить её на гитхаб не удаётся, но можно найти её по ссылке на яндекс-диск: https://disk.360.yandex.ru/d/lY3htb6ReThBQw.

При построении эмбеддингов документов мы получаем усреднённый эмбеддинг слов, входящих в него. То же самое при обработке запроса: усреднённый эмбеддинг термов из запроса. Для оценки используется косинусная близость.

Код с реализацией этого метода находится в файле ```fasttext.py```.

## Вспомогательные файлы

Кроме представленных трёх файлов, где непосредственно реализуются методы поиска (классы с методами ```.fit()``` и ```.search()```), в папке также находятся:

1) ```preprocess_query.py``` -- вспомогательный файл для предобработки запроса: лемматизация, удаление стоп-сло и прочее, как и для предобработки текстов в корпусе;
2) ```search.py``` -- файл, который сводит все методы поиска в один класс;
3) ```cli.py``` -- файл для реализации CLI.
